# Databeez UI — Design System

Benvenuto nel design system ufficiale di **DataBeez.ai**.

Questa libreria raccoglie tutti i componenti React, i token di design e le utility CSS usati nel portale `databeez-swarm`. L'obiettivo è garantire **consistenza visiva**, **accessibilità** e **riutilizzabilità** in tutti i progetti del team.

## Struttura della sidebar

**🎨 Design Tokens** — Palette colori light/dark, tipografia, spaziatura, ombre e animazioni.

**🎛 Theme** — `ThemeProvider`, `useTheme()` e lo script anti-FOUC da iniettare nel `<head>`.

**🧩 Components** — 25 componenti pronti all'uso:

- **Form** — `Input`, `InputWithIcon`, `SearchInput`, `Textarea`, `Select`
- **Display** — `Button`, `Badge`, `StatusBadge`, `MethodBadge`, `Spinner`
- **Layout** — `Card`, `PageHeader`, `TabSwitch`, `Tabs`
- **Feedback** — `Alert`, `EmptyState`, `Skeleton`
- **Content** — `CodeBlock`, `CopyButton`, `FeatureCard`, `StatCard`
- **System** — `Table`, `Dialog`, `StatusIndicatorRow`

## Installazione

### Produzione (GitHub Packages)

```bash
npm install @databeez/ui
```

Aggiungi al `.npmrc` del progetto le credenziali per il registry GitHub:

```
@databeez:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=YOUR_GITHUB_TOKEN
```

### Sviluppo locale (due repo in parallelo)

Se stai modificando i componenti in contemporanea con un progetto consumatore,
usa il `file:` path per avere hot-reload immediato senza pubblicare:

```json
// package.json del progetto consumatore
{
  "dependencies": {
    "@databeez/ui": "file:../databeez-ui"
  }
}
```

Esegui `npm install` nel progetto consumatore: npm crea un symlink a questa cartella.

> **Importante (Next.js):** aggiungi `transpilePackages: ['@databeez/ui']` nel `next.config.js`
> del progetto consumatore. Senza questa opzione Next.js cerca i file compilati in `dist/`
> invece di usare i sorgenti TypeScript direttamente — e le modifiche non sono visibili senza
> un `npm run build` preventivo in `databeez-ui`.
>
> ```js
> // next.config.js
> const nextConfig = {
>   transpilePackages: ['@databeez/ui'],
> }
> ```

> **Attenzione:** con `file:` path le dipendenze di `@databeez/ui` non vengono hoisate
> automaticamente. Se il progetto consumatore usa direttamente un pacchetto già presente
> qui (es. `react-syntax-highlighter`, `lucide-react`), dichiaralo anche nel suo `package.json`.

---

## Integrazione in un progetto Next.js

```js
// 1. next.config.js — abilita la compilazione dei sorgenti TypeScript del pacchetto
const nextConfig = {
  transpilePackages: ['@databeez/ui'],
}
module.exports = nextConfig
```

```js
// 2. Estendi tailwind.config.js
const databeezeConfig = require("@databeez/ui/tailwind.config")
module.exports = {
  presets: [databeezeConfig],
  content: [
    "./app/**/*.{js,ts,jsx,tsx}",
    "./node_modules/@databeez/ui/src/**/*.{js,ts,jsx,tsx}",
  ],
}
```

```tsx
// 3. Importa i token CSS nel layout root
import "@databeez/ui/globals.css"

// 4. Usa i componenti
import { Button, Card, StatusBadge } from "@databeez/ui"
```

## Dark mode (anti-FOUC)

```tsx
// app/layout.tsx
import { THEME_ANTI_FOUC_SCRIPT, ThemeProvider } from "@databeez/ui"

export default function RootLayout({ children }) {
  return (
    <html lang="it">
      <head>
        <script dangerouslySetInnerHTML={{ __html: THEME_ANTI_FOUC_SCRIPT }} />
      </head>
      <body>
        <ThemeProvider>{children}</ThemeProvider>
      </body>
    </html>
  )
}
```
